# スワイプ廃止・拡大率

- 誤操作対策としてActivity全体の横スワイプ検出を削除。ハンバーガーメニューはアイコンのタップでのみ開く。
- 本文の二本指ピンチは設定「編集表示」の「ピンチ操作で拡大・縮小」で切り替える。デフォルト無効。無効時は検出器を通さず標準の編集操作へ渡す。有効時のみ `ScaleGestureDetector` で検出し、複数指の間は通常のテキスト入力・選択のタッチをキャンセルして、指がすべて離れるまで消費する。一指のスクロールやタップは従来通り。ダブルタップのQuickScaleは無効。
- 拡大率25〜400%、初期値100%。設定ページの基本フォントサイズに対する倍率として、本文・行番号・行間・表示記号を拡大。テキストの内容、履歴、未保存フラグは変更しない。倍率を端末内の設定へ保存する。
- 右上メニューは標準PopupMenuを使用。従来の７操作を維持し、最下部に「拡大率」を追加。選択後のダイアログに「−」「数値入力」「%」「＋」を配置。ボタンは10ポイント刻み、入力は有効な範囲の整数を反映する。完了時に不正値は入力欄でエラー表示し、ダイアログを閉じない。ピンチ無効時もダイアログから調整できる。
- マイナス素材はGoogle Material Design Iconsの `src/content/remove/materialicons/24px.svg`（Apache-2.0）。原本は `docs/icon-sources/remove.svg`、ライセンスは同ディレクトリのLICENSE。VectorDrawableへ変換し色を変更した。
- 手動確認: 横スワイプでメニューが開かない、一指でスクロール、ピンチで拡縮、本文や未保存状態の不変、倍率の上下限、＋/−/入力とピンチの同期、回転・設定変更・再起動後の倍率維持、キーボード表示中/横画面でメニューの最下部まで操作できること。実機操作テストは未実施。
- 自動確認: `./gradlew assembleDebug testDebugUnitTest lintDebug --offline` 成功。倍率の単体テストを2件追加。Lintは警告が残るがエラーなし。
- ダイアログ化とピンチ設定追加後も同コマンドが成功（単体テスト25件）。追加の手動確認: 未設定時はピンチ無効、設定ON/OFFと再起動後の保持、OFFのまま右上「拡大率」から調整可能、−/入力/＋、不正入力で完了できないこと。これらの実機UI確認は未実施。
