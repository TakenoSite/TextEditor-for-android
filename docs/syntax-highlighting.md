# オフライン構文ハイライト

## 要件と設計
- C/C++、Python、JavaScript/TypeScript、Java、Kotlin、C#、Go、Rust、Swiftをファイル拡張子（大文字小文字不問）で判定。
- 判定ルールは `SyntaxLexer.kt`、ライト／ダーク用配色は `res/values/syntax_colors.xml` に同梱。インストール直後からオフラインで使用可能。ダウンロード、外部スクリプト、コード実行は行わない。
- 編集本文を文字列にコピーし、専用の共有ワーカー1本で解析。入力から160ms待って開始し、古い世代の結果は反映しない。画面を離れるとキャンセル、破棄時にリスナーを解除。
- 独自のForegroundColorSpanだけを付与／除去する。本文、IMEの編集中情報、選択、保存・共有内容、Undo/Redoには手を加えない。対応言語は等幅表示、それ以外は元の書体。
- キーワード、組み込み型、数値、文字列、コメント、前処理命令／注釈を色分け。コンパイラーではない簡易字句解析のため、文字列補間の内部、JS正規表現、JSX/TSXタグ、複雑なマクロなどの厳密解析は対象外。Markdownのコードブロックの色分けは今回の対象外。
- 負荷対策: 本文50万UTF-16文字超では色分けなし、最大2万トークンまで。編集と保存は従来どおり可能。

## 検証
- JVMテストで11言語の検出・キーワード、コメント優先、複数行／raw文字列、エスケープ、数値、範囲の妥当性、サイズ上限を確認。
- 端末確認: 機内モードで対応ファイルを開く→入力／削除→保存→開き直し。ライト／ダーク、日本語IME、Undo/Redo、テーマ／言語変更、別名保存による拡張子変更を確認する。実機での表示・操作・性能は未確認。
