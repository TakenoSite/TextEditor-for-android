# 起動時のファイル再オープン

- 通常の新規起動時、最後に正常に開いた／保存したファイルのURIとローカルパスをeditor設定から取得して読み込む。既存利用者で設定がない場合は最新履歴を使用。
- 成功時のみ記録を更新。失敗したファイルを別ファイルで置き換えたり、自動で権限画面を開いたりしない。既存の履歴用アクセス通知カードから権限付与・再選択を行う。
- 保存済みインスタンス状態（本文・選択・未保存状態）の復元を最優先し、外部VIEW/EDITの指定ファイルを次に優先。いずれも通常起動の再オープンで上書きしない。
- 新規作成／閉じるで最後に開いたファイルの記録は消さない。本文クリアでも維持する。保存先変更に成功した場合は新しい保存先を記録する。
- 未保存本文の永続バックアップではなく、ディスク上の保存内容を読み直す機能。
- 手動確認項目（未実施）: ファイルを開く→アプリ終了→再起動、保存先変更後の再起動、外部ファイル指定、画面回転中の未保存内容保持、削除・移動・失効URIで通知から復旧、履歴なしの初回起動。
