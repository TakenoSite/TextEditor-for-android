# 設定ページと表示機能

## 合意した要件
- テーマと言語のプルダウンを独自UIで統一。角丸の選択欄、テーマの太陽／月アイコン、下向き矢印、選択メニューのチェック表示。標準Spinnerの見た目を使用しない。
- 初回起動時、言語が未設定の場合に日英併記の言語選択ダイアログを表示。選択後「はじめる / Continue」で確定。設定済みの既存利用者には再表示しない。
- 初回ダイアログはグレー系の専用配色（ライト／ダーク連動）。アイコン、選択背景、チェック、開始ボタンも無彩色に統一。「あとから設定で変更できます / You can change this later in Settings」の補足文は表示しない。設定画面の緑アクセントは維持する。
- 設定の最下部（ファイルアクセスの後）に言語プルダウンを追加。「日本語」「English」を各言語の自称で表示。初期値は従来どおり日本語、選択をアプリ再起動後も保持。
- 設定のサンプル図形・補足説明は表示しない。検索カードの初期例文も削除し、操作結果やエラーだけを表示する。本文の改行表示は行ごとの保存形式に対応し、LFは `←`、CRLFは初期の `↵`、CRは `CR` とする。ヘッダーのコード名表示は変更しない。
- 設定への入口はハンバーガーメニューだけ。右上のオーバーフローメニューからは削除。
- 設定は専用のページで表示し、カテゴリーに分ける。
- ライト/ダークの明示的な二択を保存する。
- 設定内の数値はすべてスライダー。行移動の番号入力は対象外。
- 改行・タブ・空白の表示記号を切り替える。上部の文字コード/改行コード情報は常時横並びで表示し、表示切り替え設定は設けない。

## 基本・詳細設計
- `AppChoiceUi`でアイコン付き選択欄とPopupWindowを共通化。配色はEditorAppearanceに従い、緑のアクセント、角丸、押下表現、選択状態、48dp以上の操作領域を使用。メニューは外側タップ／戻るで閉じ、選択欄の破棄時にも解放。
- `LanguageSetupDialog`はDialogFragmentで回転時の選択を維持。language未保存かつlanguage_setup_complete=falseなら表示し、確定時に両方保存してActivityを再生成。本文等は既存の退避処理で保持。言語選択中はMD描画・構文解析を開始しない。端末の言語設定は変更しない。
- 言語: `SharedPreferences(editor).language` にja/enを保存。`LocalizedActivity`で各ActivityのリソースContextにだけロケールを適用。端末全体の設定やLocaleのグローバル値は変更しない。設定画面は選択時再生成し、編集／履歴／ヘルプはonResumeで言語差分を検出して再生成する。再生成待ちの編集画面ではプレビューの再描画を開始しない。
- 通常の値/values-enリソースでメニュー、検索、ダイアログ、設定、ヘルプ、履歴、通知、読み上げラベルを切り替える。Android自身のファイル選択・許可画面や提供元の例外メッセージはOS／提供元の言語に依存する。本文と既存のファイル名は翻訳しない。新規ファイルの既定名のみ作成時の言語に合わせる。
- 再生成時の本文・未保存状態・Undo/Redo・URI・選択・拡大率・プレビューモードは既存のEditorStateStore退避で維持（古い記述の大容量Bundle方式は現在使用しない）。初期選択コールバックで設定が変更されないよう保存値と比較し、同一言語では再生成しない。
- `SettingsActivity` を非公開Activityとして追加。戻る矢印・システムの戻るで編集画面に戻る。スクロール可能な４カテゴリー（テーマ/編集表示/記号・ファイル情報/自動保存）をカードで区別。
- `SharedPreferences(editor)` を引き続き使用。変更時に保存し、メイン画面は onResume で反映。
- 数値: 文字サイズ10–32sp、行間0–16dp、自動保存待ち時間1–10分。アクセシビリティ用のスライダー名も指定。
- `Theme.HelloWorld`（ライト）と `Theme.Editor.Dark`（ダーク）を使用。設定側の配色切り替えで再生成し、編集画面への復帰時にもテーマ変更を検出。本文、選択、履歴、URI、未保存状態、元の改行、検索オプションをBundleで引き継ぐ。
- `EditorAppearance` で実行時の背景/文字/アイコン/ナビゲーション/ファイル操作メニュー/検索の文字色を揃える。AppCompatテーマを使用し、Materialカスタムボタン背景は使用しない。
- `WhitespaceEditText` の onDraw で ↵ / → / · / □ を重ね描き。Editableには一切挿入しないため保存、コピー、検索、Undoに表示設定が影響しない。可視行のみ描画する。カスタムビューのためMeta-Appプレビューでは本文入力欄が省略される可能性がある。メインレイアウトは引き続き `activity_main.xml`。
- UTF-8情報の右隣に LF/CRLF/CR/混在 を表示する独立した情報行をヘッダーに追加。情報行は常時表示し、旧 `show_info` 設定がfalseでも非表示にしない。パスも表示を維持。
- 内部編集テキストはLFに正規化。保存時は読み込み元の改行形式を使用。混在ファイルは行番号順に元の改行形式を適用し、新たな行は先頭の改行形式（新規ファイルはLF）を使用する。行を移動した際に改行種別自体が一緒に移動する方式ではない。

## ユーザーテスト手順
0. 新規インストール時に日英併記の初回ダイアログ→English選択→確定→英語表示、再起動してダイアログが出ないこと。回転で選択が保持されること。設定済み利用者には出ないこと。テーマ／言語メニューのアイコン・チェック、外側タップ／戻る、ライト／ダーク、大きい文字・読み上げも確認（端末未確認）。
0. 設定を最下部までスクロール→言語プルダウンでEnglish→設定・編集メニュー・検索・履歴・ヘルプが英語になること。アプリ再起動後も維持。日本語に戻せること。ライト／ダーク両方、未保存本文とUndo・カーソル位置の保持、MDプレビューからの復帰、大きな文字サイズ時の項目可読性を確認。端末実機では未確認。
1. 本文に未保存の文字を入力→ハンバーガーから設定→４カテゴリーを確認。右上メニューには設定がないこと。
2. ダーク→ライトを切り替えて編集画面に戻る。内容・未保存状態・カーソル位置・元に戻すを維持し、ツールバー・カード・ダイアログの可読性を確認。
3. 各スライダーの最小/最大を操作→編集画面で文字サイズと行間を確認。アプリの再起動で設定が残ること。
4. 改行・タブ・半角/全角空白を含む本文で表示を個別に切り替える。コピーした内容や保存ファイルに記号が混入しないこと。
5. LF/CRLF/CR/混在のファイルを開き、ヘッダー表示と保存後の改行形式を確認。文字コードと改行コードが常時横並びで表示され、設定に情報表示スイッチがないこと。
6. 自動保存OFFとON（1分）で未保存状態の変化と保存内容を確認。新規ファイルは勝手に保存しないこと。
