# 設定ページと表示機能

## 合意した要件
- 設定のサンプル図形・補足説明は表示しない。検索カードの初期例文も削除し、操作結果やエラーだけを表示する。本文の改行表示は行ごとの保存形式に対応し、LFは `←`、CRLFは初期の `↵`、CRは `CR` とする。ヘッダーのコード名表示は変更しない。
- 設定への入口はハンバーガーメニューだけ。右上のオーバーフローメニューからは削除。
- 設定は専用のページで表示し、カテゴリーに分ける。
- ライト/ダークの明示的な二択を保存する。
- 設定内の数値はすべてスライダー。行移動の番号入力は対象外。
- 改行・タブ・空白の表示記号を切り替える。上部の文字コード/改行コード情報は常時横並びで表示し、表示切り替え設定は設けない。

## 基本・詳細設計
- `SettingsActivity` を非公開Activityとして追加。戻る矢印・システムの戻るで編集画面に戻る。スクロール可能な４カテゴリー（テーマ/編集表示/記号・ファイル情報/自動保存）をカードで区別。
- `SharedPreferences(editor)` を引き続き使用。変更時に保存し、メイン画面は onResume で反映。
- 数値: 文字サイズ10–32sp、行間0–16dp、自動保存待ち時間1–10分。アクセシビリティ用のスライダー名も指定。
- `Theme.HelloWorld`（ライト）と `Theme.Editor.Dark`（ダーク）を使用。設定側の配色切り替えで再生成し、編集画面への復帰時にもテーマ変更を検出。本文、選択、履歴、URI、未保存状態、元の改行、検索オプションをBundleで引き継ぐ。
- `EditorAppearance` で実行時の背景/文字/アイコン/ナビゲーション/ファイル操作メニュー/検索の文字色を揃える。AppCompatテーマを使用し、Materialカスタムボタン背景は使用しない。
- `WhitespaceEditText` の onDraw で ↵ / → / · / □ を重ね描き。Editableには一切挿入しないため保存、コピー、検索、Undoに表示設定が影響しない。可視行のみ描画する。カスタムビューのためMeta-Appプレビューでは本文入力欄が省略される可能性がある。メインレイアウトは引き続き `activity_main.xml`。
- UTF-8情報の右隣に LF/CRLF/CR/混在 を表示する独立した情報行をヘッダーに追加。情報行は常時表示し、旧 `show_info` 設定がfalseでも非表示にしない。パスも表示を維持。
- 内部編集テキストはLFに正規化。保存時は読み込み元の改行形式を使用。混在ファイルは行番号順に元の改行形式を適用し、新たな行は先頭の改行形式（新規ファイルはLF）を使用する。行を移動した際に改行種別自体が一緒に移動する方式ではない。

## ユーザーテスト手順
1. 本文に未保存の文字を入力→ハンバーガーから設定→４カテゴリーを確認。右上メニューには設定がないこと。
2. ダーク→ライトを切り替えて編集画面に戻る。内容・未保存状態・カーソル位置・元に戻すを維持し、ツールバー・カード・ダイアログの可読性を確認。
3. 各スライダーの最小/最大を操作→編集画面で文字サイズと行間を確認。アプリの再起動で設定が残ること。
4. 改行・タブ・半角/全角空白を含む本文で表示を個別に切り替える。コピーした内容や保存ファイルに記号が混入しないこと。
5. LF/CRLF/CR/混在のファイルを開き、ヘッダー表示と保存後の改行形式を確認。文字コードと改行コードが常時横並びで表示され、設定に情報表示スイッチがないこと。
6. 自動保存OFFとON（1分）で未保存状態の変化と保存内容を確認。新規ファイルは勝手に保存しないこと。
