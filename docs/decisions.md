# テキストエディター: 設計と確認

- 下部右端の×は「閉じる」から「テキストをクリア」に変更。確認後、Editableを空にする通常編集として処理し、ファイルの関連付け・保存先・元の改行情報は保持。既存TextWatcherによりUndo/Redo、未保存表示、自動保存待機を反映する。空本文では何もしない。読み取り専用ではクリア不可。上部ファイルメニューの「閉じる」は従来通り。

- ヘルプを３区分・目次付きの専用ページへ移行。説明内容と動的バージョン情報の設計は `help-design.md` を参照。

- 上部メニューの重複を整理。「開く (SAF)」は「開く」と同じOpenDocument処理のため削除。右上の「別名で保存」は削除し、ファイルメニューの「名前を付けて保存」に集約。下部のショートカットと他の機能は維持。

- ユーザーが「すべてのファイルへのアクセス」を選択したため、MANAGE_EXTERNAL_STORAGEの許可導線と共有ストレージのパスによる履歴再開を追加。クラウド等のSAFは維持。詳細は `all-files-access.md`。

- 改行記号の折り返し・スクロール時のずれを修正。二重スクロール補正の除去、本文Layout基準のbaseline、記号幅の予約、折り返し時の横位置リセット。調査内容と回帰テストは `marker-debug.md`。

- 「最近使用したファイル」は履歴URIを再オープンできる専用ページへ変更。永続化・並び順・権限の扱いとテスト手順は `recent-files.md` を参照。

- 設定はハンバーガーから開く専用ページへ移行し、右上メニューから削除。テーマ、スライダー、表示記号、改行形式と保存に関する設計・確認手順は `settings-design.md` を参照。

- 検索結果の通知カード（編集画面上部と検索カード内）には右端に48dpの閉じるアイコンを配置。閉じても検索条件は維持し、次の検索・置換で再表示する。ナビゲーションを開く際は選択範囲を解除して編集欄のフォーカスを外し、カーソルとキーボードを非表示にする。編集欄への再フォーカス時にカーソルを戻す。

- 正規表現は Java Pattern、MULTILINE を使用。置換の `$1` 形式のグループ参照を有効にし、通常モードでは置換文字をリテラルとして扱う。単一置換は全文の一致を検証し、後読みなどの文脈を保持。
- 正規表現モードで先頭が `*` の式はファイル名ワイルドカードとして扱う（例 `*.txt`）。この互換モードは `*` と `?` 以外をリテラルとし、空白・パス区切りを越えない。他の入力は通常の正規表現。検索カード内に説明を表示する。
- 検索カードを開いたまま一致位置・不一致・式エラー・置換結果をカード内に表示し、トーストは使わない。カードを閉じて下部の検索矢印を押す場合にも編集面上部の通知欄に結果を表示。`*.txt` の回帰テストを追加し、ビルドと単体テストが成功。実機UI確認は未実施。
- 正規表現修正確認: `assembleDebug testDebugUnitTest --offline` 成功。検索・グループ置換・各行のアンカー・通常置換・後読み・空白・不正式について６件のテストを追加。実機UIテストは未実施。

- ハンバーガーはダイアログではなく、左から320msで開くカード型ナビゲーションを表示。既存の６項目と操作を維持。背面は暗くして操作を遮断し、背景タップ・戻る・項目選択で280msで閉じる。狭い画面では幅84%、最大300dp、項目リストはスクロール可能。
- 横スワイプからカードを開く機能は誤操作対策として廃止。本文の二本指拡大縮小と右上メニューの倍率入力を追加。詳細と確認手順は `zoom-design.md` を参照。

- 参考画像の淡いグレーの編集面、細い行番号列、ファイル名とパスのヘッダー、下部の操作列、緑色のアクセントを採用。メイン画面は `activity_main.xml` に保持する。
- Android Storage Access Framework を使い、開く・新規保存・上書きを実装。外部ファイルマネージャーの VIEW/EDIT インテント (`text/*` など) を受け取る。UTF-8 で読み書きし、上書きが禁止された URI は別名保存を案内する。
- 検索/置換、履歴、行移動、文字数、共有、行番号・折り返し・文字サイズ・任意の自動保存を用意。初期状態では自動保存しない。未保存の変更を破棄するときは確認する。
- 操作のアニメーションは Android 標準のダイアログ・ポップアップ・タッチ応答だけに限定。巨大なファイルは通常の EditText に一括で読み込む方式のため、大容量ファイルは対象外。
- 手動確認: 新規入力→別名保存→再オープン→編集→上書き→再オープン、ファイルマネージャーから .txt を「開く」、戻る/やり直す、検索/置換、未保存警告、回転時の編集内容、読み取り専用 URI からの別名保存を確認する。
- 上部のファイルアイコンは画像の７項目メニューを開く。「開く」「開く (SAF)」はいずれも再起動後の履歴に対応する `OpenDocument`。再読み込み・閉じるときも未保存の編集は確認し、保存できないときは別名保存を案内する。失効した履歴は通知カードの再選択から権限とリンクを更新する。
- アイコンは Google の無料素材 [Material Design Icons](https://github.com/google/material-design-icons) から SVG を取得し、Android VectorDrawable に変換。原本は `docs/icon-sources/*.svg`、ライセンス全文は `docs/icon-sources/LICENSE`（Apache License 2.0）。変換時は背景用の透明パスを除外し、色をグレーに設定した。メニュー・編集・ファイル操作・下部のアイコンで共通利用する。
